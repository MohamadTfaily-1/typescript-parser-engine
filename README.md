
# TypeScript Parser Engine

A TypeScript project that parses CSV, JSON, and XML order files into JavaScript objects.

## Features

- CSV parser for cake orders
- JSON parser for book orders
- XML parser for toy orders
- Input validation and error handling
- Automated tests using Jest and ts-jest
- Code quality checks using ESLint

## Installation

npm install

## Run

npm start

## Run Tests

npm test -- --runInBand

## Check Code Quality

npm run lint
